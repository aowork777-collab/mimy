# 本番化の残作業（権限・共有予約・チャット実装後）

## 今回実装した範囲

- メールallowlistの管理者、DBで承認するキャスト、通常利用者の認可
- 全利用者共有シフトの原子的な予約取得（部分一意インデックス）
- シフト追加・公開停止、キャスト申請・審査・プロフィール
- 当事者間の予約チャット。送信者をセッションから決定し、第三者と管理者の会話閲覧を拒否
- 審査・シフト・予約の監査記録

現状は1時間枠全体を占有します。可変開始時間・短時間予約を詰める運用へ変更する場合、区間の重複防止を別途実装します。予約前のやり取りは提供しません。キャンセル後は既存メッセージを読めますが追記不可です。

## 外部契約・接続が必要

- 決済会社の事業審査・契約、Webhook署名検証、決済額検証、冪等性、実返金
- 音声通話サービスの契約・参加者トークン・入退室・終了制御・再接続
- メール・LINE通知と送信失敗時の再送
- 本人・年齢審査、正式事業者情報・規約・プライバシー・キャンセル方針

管理者は `ADMIN_EMAILS` をsecretとして設定。Sitesで所有者として確認したメールを初期設定しています。一般公開前にアクセス権、担当者、連絡先、退会・削除方針を再確認してください。

## 追加開発

- 実支払いと返金を予約から独立した台帳へ分離
- 期限切れ後に決済通知が届いた場合の在庫再取得・返金待ち処理
- キャスト報酬率のスナップショット、精算・明細・送金
- 会話練習の振り返りフォーム、通報対応ステータス、ブロック
- 退会・データ削除・保存期限・データ量の上限とページング
- rate limit、監視、エラー通知、バックアップ復元検証
- 実機でのアクセシビリティとブラウザ全フロー確認

## 検証状況

SQLiteに実際のSQLマイグレーションを適用し、複数利用者の競合予約、別キャストのシフト操作拒否、承認前の権限拒否、送信者偽装、当事者以外のチャットアクセス拒否、キャンセル・期限切れによる枠解放をテストします。

このテストは外部決済やCloudflare上の実ネットワーク競合の検証を代替しません。所有者限定のままでは実際の別アカウント参加者はサイトへ入れません。Sites側でテスト参加者を招待した後、管理者・キャスト・利用者の3アカウントで最終確認してください。
