# スマホ画面の調整ガイド

画面構成は `app/page.tsx`、表示ルールは `app/globals.css` の末尾にある
`Responsive refresh` セクションで調整できます。API・予約計算・権限は変更していません。

| 画面幅 | レイアウト |
| --- | --- |
| 600px以下 | 写真と紹介は縦並び、キャストは1列、シフト入力は縦並び |
| 601〜1000px | ヒーローは2列、検索欄は折り返し、キャストは幅に応じて2〜3列 |
| 1001px以上 | 既存の広いレイアウトを保持 |

## デザインの意図

- Airbnbの検索条件をまとめる構成を参考に、キャストの検索と表示切替を同じパネルに配置。
- 写真→名前・料金→ひとこと→空き時間→予約の順番で比較しやすく表示。
- 小さい操作対象を避けるため主なボタンは44〜56px、入力欄は16pxの文字を使用。
- ヘッダーは横スクロール可能にして、管理者の追加メニューも隠さず保持。
- 長い名前・話題・金額は折り返し、画面全体の横スクロールを防ぐ。

参考: https://www.airbnb.jp/

## 手元で確認する手順

1. `pnpm dev` を起動し、表示されたURLを開きます。
2. Chromeの開発者ツールでデバイスツールバーを有効にします。
3. 幅320・375・390・768・1280pxで、検索、プロフィール、予約、ログインを確認します。
4. 各権限の実アカウントで管理・シフト・チャット画面を確認します。
5. iPhone/Androidでも入力時のズーム、キーボード、横スクロールを確認します。

料金・同意チェック・送信条件は既存の実装を使用します。CSSだけで操作を有効化しないでください。
