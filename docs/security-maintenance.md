# セキュリティ対策の保守

更新日：2026年11月8日（日本時間）。この資料は安全性の保証・第三者認証ではありません。

## 今回の変更

| 対象 | 保護 | 実装 |
|---|---|---|
| メッセージ | 直近60秒・アカウントごと20件。全予約を合算 | `lib/workspace-service.ts` |

### メッセージ制限

既存の予約当事者・予約状態の確認に加えて、カウントとINSERTを**1つのSQL文**で実行します。プロセス内のカウンターではないため、Workerやタブが複数でも同じ枠を共有します。

- 上限時はHTTP `429`、`Retry-After`（秒）と日本語の説明を返します。
- 送れなかった本文は画面に残り、待ってから再送できます。自動再送はしません。
- 別の利用者・キャストの枠は消費しません。
- `0005_thin_alice.sql` は送信者・日時の検索用インデックスだけを追加します。既存データは削除しません。
- これはメッセージ保存の連投防止です。ログイン、写真、通報など他のAPI全体のレート制限を実装したものではありません。

### 写真のプライバシー

JPEG・PNG・WebPと3MBの上限は維持します。サーバーでコンテナ構造を確認し、許可した画像データだけを組み立て直します。JavaScriptのみで動き、外部の画像変換サービスや追加の有料サービスは使いません。

- 元のEXIFはコピーせず、必要な場合だけ**向きの数値1項目**から新規EXIFを作ります。GPS・撮影日時・作者などは含みません。
- 画素の圧縮データは再圧縮せず、画質の再圧縮劣化を避けます。透過・アニメーションも保持します。
- ICCプロファイルも除去するため、そのプロファイルに依存する写真は色味が変わる場合があります。
- ファイルの末尾の余分なデータ、JPEGの埋め込みサムネイル、PNGのテキスト・未定義補助チャンク、WebPの未知チャンクも除去します。
- 過去にR2へ保存した写真も配信前に処理します。保存済みの古いデータは、初回閲覧時にETag条件付きで置換します。新しいアップロードと競合しても上書きしません。未閲覧の旧オブジェクトは置換されるまで元データが残ります。
- 過去の外部HTTPS画像URLは対象外です。外部URLを使用しているキャストは写真をアップロードし直してください。
- 写真に写り込んだ文字・住所、画素に隠された情報は消しません。完全な画像デコード検証やマルウェア検査ではありません。

### ライブラリ

Next.js / React / Vite / Zodを修正版に更新しました。間接依存の既知の問題も `pnpm-workspace.yaml` の `overrides` で修正版へ固定しています。アプリは従来どおりVinextとCloudflare Workersで実行します。パッケージ監査の該当と、本番での攻撃成立は区別してください。

`minimatch`・`satori`・`zod`にはメジャーをまたぐ更新も含まれるため、固定を外すときは型チェック・ビルド・既存の機能テストを必ず実行します。サイトで未使用のOG画像生成など、依存ライブラリの全APIを検証したものではありません。

## 検証の境界

ローカルのSQLite・R2/LiveKitのモックを用いたテストです。写真には個人情報を含まない人工画像を使っています。本番のD1・R2・認証境界、実際の複数端末通話、ブラウザーの描画は別途確認が必要です。
